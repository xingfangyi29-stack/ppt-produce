# PPT Produce — Engagement Survey Discussion Assistant (Project Skeleton)

This repository contains a minimal project skeleton for the Engagement Survey Discussion Assistant.

Purpose
- Provide a local dev skeleton with frontend (React + Vite) and backend (FastAPI) so you can start developing the application.

What is included
- frontend/: React + Vite application (TypeScript)
- backend/: FastAPI application with a simple health endpoint
- docs/: basic docs placeholder
- sample_data/: placeholder for sample PPTX files

See docs/ and backend/README.md and frontend/README.md for usage.
